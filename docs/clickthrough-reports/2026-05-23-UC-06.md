### CT-001 — Missing `<title>` on `/harvest` causes screen reader to announce "untitled page" [P2]
- **UC:** UC-06
- **Route:** `apps/web/src/routes/harvest/+page.svelte`
- **Expected (per SvelteKit convention and field a11y requirement):** The page title should identify the page (e.g., "Harvest — CropCard") so that screen-reader users hear a meaningful announcement when navigating to `/harvest`.
- **Observed:** `document.title` is `""`. The SvelteKit route announcer (`#svelte-announcer`, `aria-live="assertive"`) announces "untitled page" on every client-side navigation to this route.
- **Console:** No errors or warnings.
- **Network:** No 4xx/5xx.
- **Screenshot:** `./screenshots/2026-05-23-UC-06-finding-01.png` (full-page post-harvest state; page title issue is DOM-level, not visually captured)
- **Recommendation:** Add `<svelte:head><title>Harvest — CropCard</title></svelte:head>` to `apps/web/src/routes/harvest/+page.svelte`.
- **Cross-ref:** Consistent with F-F noted in the UC-06 audit notes regarding placeholder-only inputs; both are accessibility/usability polish items. Likely systemic across other routes.

### CT-002 — "Recorded harvests" table Block column shows truncated UUID instead of block name [P2]
- **UC:** UC-06
- **Route:** `apps/web/src/routes/harvest/+page.svelte` (harvest records table)
- **Expected (per UC-06 Success criteria):** The recorded-harvest confirmation should be readable by the farmer. The "Block" column should show the human-readable block name (e.g., "Block-C") as the planting list above already does.
- **Observed:** The "Block" cell renders `53a7cbda…` — a truncated database UUID/hash — not the block name. The farmer cannot identify which block was harvested from the table without cross-referencing the UUID.
- **Console:** No errors.
- **Network:** No 4xx/5xx.
- **Screenshot:** `./screenshots/2026-05-23-UC-06-finding-01.png` (table visible in lower portion of full-page screenshot)
- **Recommendation:** Join the `blocks` table in the harvest list query and pass `block.name` to the frontend; render the name in the "Block" column instead of the block ID.
- **Cross-ref:** None from prior audit.
