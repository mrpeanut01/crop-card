## Findings

### CT-001 — `<details>` summary label is uninformative ("detail") [P2]
- **UC:** UC-03
- **Route:** `apps/web/src/routes/spray/+page.svelte` — STOP card section
- **Expected (per UC-03 primary path step 3):** `<details>` expandable element for the JSON kernel evaluation should have an accessible label describing its content (e.g., "Kernel evaluation JSON" or similar) so screen-reader users know what the disclosure contains before activating it.
- **Observed:** `<summary class="s-igyK9zoPIZoL">detail</summary>` — the literal text "detail". No `aria-label` on either the `<summary>` or the `<details>` element. A screen-reader announces this as "detail, collapsed, button" — meaningless to the user.
- **Console:** No errors.
- **Network:** `POST /api/spray/evaluate` 200.
- **Screenshot:** `./screenshots/2026-05-23-UC-03-details-summary.png`
- **Recommendation:** Change the `<summary>` text from "detail" to something descriptive, e.g., "Kernel evaluation JSON" or "Show raw evaluation". No aria attributes required if the visible text is meaningful.
- **Cross-ref:** Related to F-A from usability-audit.md (STOP card a11y concerns). This is a separate, new gap — contrast is F-A; the summary label issue was not previously recorded.
