# Contributing

Thanks for the interest in Crop Card.

This project is moving quickly, and the codebase can change fast as ideas are tested and shipped. Development is heavily AI-assisted, with Claude Code helping accelerate iteration, so implementation details may evolve rapidly.

At this stage, the most valuable outside help is usually not direct coding help. What is most helpful right now is thoughtful input on the app itself: functionality, workflow, UX, edge cases, feature gaps, priorities, and places where the product could be simpler or more useful.

Suggestions, bug reports, product feedback, and well-scoped feature ideas are strongly encouraged. If you have an idea, please open an Issue or start a Discussion so it can be reviewed before any implementation work begins.

Code contributions are reviewed very selectively. Please do not open large unsolicited pull requests. Pull requests tied to an approved Issue are much more likely to be considered, and even then, small focused changes are preferred over broad refactors.

In short: feedback on what the app should do is usually more valuable right now than help writing the code for it.
