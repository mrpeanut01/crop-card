## Findings

### CT-001 — Companion Advisor has no visible Close/X button in modal header [P2]
- **UC:** UC-07
- **Route:** `apps/web/src/routes/plan/+page.svelte` (line 4302–4341)
- **Expected (per use-cases.md UC-07):** The companion advisor modal/dialog should have an accessible dismiss affordance visible in the modal header, consistent with the "Select a crop variety" dialog which has a "Close ✕" button at the top right.
- **Observed:** The `[role="dialog"]` for the companion advisor contains only "Add all N companions" and "No thanks" per-suggestion buttons. There is no ✕ or "Close" button in the modal heading area. Dismissal is possible via: (a) clicking any "No thanks" button (dismisses all suggestions at once), (b) clicking the backdrop, (c) pressing Escape — but none of these affordances are labeled or visible in the modal chrome itself.
- **Console:** No errors
- **Network:** No 4xx/5xx
- **Screenshot:** ./screenshots/2026-05-24-UC-07-finding-01.png
- **Recommendation:** Add a labeled "✕ Close" button to the `.advisor-modal` heading row, consistent with the "Select a crop variety" dialog. The button should call `dismissAdvisor()`. The Escape key and backdrop click can remain as secondary affordances.
- **Cross-ref:** Confirms finding noted in UC-01 walkthrough ("companion advisor modal/dialog has no top-level close button"). Same surface, same issue.

### Observation (not a finding): Companion advisor does not fire without a planting date

The advisor is intentionally gated on `plantingDateMs !== null` (source code verified). This is correct behavior — offset dates cannot be computed without a base date. The planting date field is labeled "(optional)" with no hint that it is required to get companion suggestions. This creates a discovery gap: a user who adds corn without a date gets no feedback that companions are available.

This is borderline P2 but is a design decision (the label says "optional" and the spec says "inline suggestion below planting form"). It is noted here for the product owner to decide whether a hint ("Add a planting date to see companion suggestions") should appear when a companion-eligible crop is selected without a date.
